📘 Python Dictionary Methods 
🔹 #1 – clear 
Removes all key-value pairs from the dictionary.
Empties it out completely for a fresh new start.

🔹 #2 – copy 
Returns a shallow copy of the dictionary.
The new copy works independently from the original.

🔹 #3 – get 
Safely retrieves the value of a specified key.
Returns None if the key isn’t found—no errors, no drama.

🔹 #4 – items 
Returns all key-value pairs as tuples in a view object.
Perfect for looping through both keys and values at once.

🔹 #5 – keys 
Returns a view of all keys in the dictionary.
Use it when you only care about the keys.

🔹 #6 – pop 
Removes the specified key and returns its value.
Optional default can prevent errors if the key’s missing.

🔹 #7 – popitem 
Removes and returns the last inserted key-value pair.
Useful when dealing with insertion order (LIFO style).

🔹 #8 – setdefault 
Returns the value of a key, or sets it with a default if missing.
Cleans up code by avoiding key existence checks.

🔹 #9 – update 
Merges another dictionary or key-value pairs into the current one.
Updates existing keys and adds new ones efficiently.

🔹 #10 – values 
Returns a view object of all values in the dictionary.
Great when you only care about the data, not the keys.
