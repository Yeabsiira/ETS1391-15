# LIST METHODS IN PYTHON

🔹 #1 – append
Adds a single item to the end of a list.
Modifies the original list directly and increases its length by one.

🔹 #2 – count
Returns how many times a specific element appears in the list.
Handy for finding duplicates or tracking values.

🔹 #3 – creation
Lists are made using square brackets [] or the list() constructor.
They can store multiple data types, including nested lists.

🔹 #4 – iteration
Looping through list elements one by one, typically with a for loop.
Useful for reading, updating, or processing items in the list.

🔹 #5 – len
Returns the total number of elements in the list.
Quick way to check a list’s size using the built-in len() function.

🔹 #6 – operation
Covers actions like merging, removing, updating, or repeating lists.
These operations help shape or manipulate list contents.

🔹 #7 – ranking
Accessing elements by index or arranging based on value or importance.
Often used in sorting or leaderboard-style comparisons.

🔹 #8 – slicing
Extracts a portion of the list using [start:stop:step] syntax.
It returns a new list without modifying the original one.

🔹 #9 – sorting
Organizes elements in ascending or descending order.
Can be done in-place or return a new sorted version of the list.
